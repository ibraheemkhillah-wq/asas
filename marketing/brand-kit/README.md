# CALL & RENT — الهوية الجديدة (Brand Kit)

كل ملفات الهوية المعتمدة في مكان واحد: اللوجو، الخطوط، الألوان، الأيقونات، وسكربتات ختام الفيديوهات.

## الألوان

| الاسم | القيمة | ملاحظة |
|---|---|---|
| البرتقالي | `#F48D57` — rgb(244,141,87) | مسحوب بالبكسل من ملف اللوجو |
| الكحلي | `#1D4563` — rgb(29,69,99) | مسحوب من نسخة اللوجو الكحلية |
| الأبيض | `#FFFFFF` | |

**الخلفيات:** متدرّجة سينمائية، مش لون مسطّح. ضوء ناعم بالنص (`#2E6896`) بينطفي لكحلي عميق عالأطراف (`#081829`)، مع فينيت بالزوايا وحبيبات ناعمة. الدالّة: `navy_field()` في `brand.py`.

## الخطوط

| الاستخدام | الخط | ملاحظة |
|---|---|---|
| العناوين العربية | Noto Kufi Arabic **Black** | أبيض، والكلمة المهمة بالبرتقالي |
| سطر عربي ثانوي | Noto Kufi Arabic ExtraBold | |
| السلوجن | Oxanium **Regular** | بدون بولد، برتقالي |
| الحساب ورقم التليفون | Tajawal **Bold** | أبيض — الخط القديم، اعتمده صاحب الشركة |

ليش هيك:
- Noto Kufi: كوفي مربّع بنهايات مسطّحة، نفس هندسة اللوجو.
- Oxanium: أقرب خط مجاني لحروف اللوجو اللاتينية. **مش نفس خط اللوجو** — حروف اللوجو مرسومة/معدّلة يدوياً. اعتمدناه لأنه أقرب واحد.

## شاشة نهاية الفيديو (المعتمدة)

المرجع: `reference/approved-end-card.png`

من فوق لتحت: اللوجو الأبيض (عرض 820px على كادر 1080×1920) ← خط برتقالي رفيع ← السلوجن ← سطرين التواصل مع الأيقونات.

**قاعدة الصوت:** صوت الفيلم بيضل لآخر المشهد الحقيقي، وبيتلاشى بنعومة خلال 0.4 ثانية. شاشة الكتابة واللوجو **بدون صوت**، بدون أي لوب أو تكرار.

## الملفات

| الملف | شو هو |
|---|---|
| `brand.py` | كل القيم أعلاه بالكود: ألوان، خطوط، `navy_field()`، `draw_slogan()`، `draw_contacts()` |
| `video-endings/ending_km.py` | ختام الكيلومترات المفتوحة — `CALLRENT-openkm-v4.mp4` |
| `video-endings/ending_kasko.py` | ختام التأمين الشامل — `CALLRENT-kasko-v2.mp4` |
| `video-endings/ending_final.py` | ختام كرسي الأطفال |
| `video-endings/ending_airport.py` | ختام المطار |

**ملاحظة:** فيلما المطار والكرسي اتركوا عمداً على نسختهم السابقة (`CALLRENT-airport-v4.mp4` و`CALLRENT-carseat-v4.mp4`). سكربتاتهم هون هي نسخة الشغل الحالية، مش بالضرورة نفس اللي بالفيديو المعتمد.

سكربتات الختام محفوظة للرجوع إلها. لتشغيلها لازم فريمات الفيلم الأصلية، وهاي مش محفوظة هون.
