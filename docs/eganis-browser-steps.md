# ربط eganis عبر المتصفّح — الخطوات

هذا الطريق لا يحتاج أي شيء من مزوّد eganis: يكفي دخولك العادي للوحة.

**المطلوب منك: ٤ أوامر على كمبيوتر المكتب، ثم ترسل لي ملفين.** بعدها أكتب أنا الربط.

> نفّذها على **كمبيوتر المكتب** لا على الخادم — لأن الخطوة الثالثة تفتح متصفّحاً
> تسجّل فيه دخولك بيدك، وهذا يحتاج شاشة.

---

## ١) تثبيت Node.js (مرة واحدة)

نزّل النسخة **LTS** من [nodejs.org](https://nodejs.org) وثبّتها بالضغط على Next حتى النهاية.

للتأكد: افتح **Command Prompt** (ويندوز: اضغط زر ويندوز، اكتب `cmd`، Enter) واكتب:

```
node -v
```

يجب أن يظهر رقم يبدأ بـ `v22` أو أعلى.

## ٢) إنزال التطبيق

في نفس النافذة:

```
git clone https://github.com/ibraheemkhillah-wq/asas.git callrent
cd callrent
npm install
npm i playwright
```

> إن لم يكن `git` مثبّتاً: افتح [صفحة المستودع](https://github.com/ibraheemkhillah-wq/asas)،
> اضغط **Code ← Download ZIP**، فُكّ الضغط، ثم افتح المجلد من Command Prompt
> واكتب `npm install` و `npm i playwright`.

التطبيق يستخدم متصفّح Chrome الموجود على جهازك. إن لم يكن لديك Chrome:

```
npx playwright install chromium
```

## ٣) تسجيل الدخول مرة واحدة

```
npm run eganis:inspect -- login
```

- سيسألك عن **رابط لوحة eganis** — انسخه من شريط عنوان المتصفّح (مثل `https://panel.eganis.com.tr`).
- ستُفتح نافذة متصفّح على اللوحة: **سجّل دخولك بيدك كالعادة** (ولو كان فيه رمز تحقق).
- بعد ما تفتح اللوحة، ارجع لنافذة الأوامر واضغط **Enter**.

تُحفظ الجلسة في `data/eganis-session.json`. **كلمة سر eganis لا تُكتب في أي ملف ولا تصلني.**

## ٤) اكتشاف اللوحة

```
npm run eganis:inspect -- auto
```

يفتح اللوحة، يقرأ قائمتها، يتعرّف على صفحات **العقود والمركبات والحجوزات والعملاء
والحسابات**، ثم يصف جداول كل صفحة: أسماء الأعمدة وترتيبها وشكل القيم.

## ٥) أرسل لي ملفين

من مجلد `data/eganis-inspect/`:

- `summary.json` — وصف الجداول والأعمدة
- `menu.json` — قائمة صفحات اللوحة

**أرقام الهواتف والهويات في العيّنات مُخفاة تلقائياً** («رقم ١١ خانة») — الشكل يكفيني
لمطابقة الأعمدة. في نفس المجلد لقطات شاشة و HTML كاملة: **راجعها ولا ترسلها إلا إذا أردت**،
ففيها بيانات عملاء حقيقية.

---

## ماذا يحدث بعدها

أكتب لك `config/eganis.json`: أي صفحة تُقرأ لكل عملية، وأي عمود يقابل أي حقل عندنا
(رقم العقد، العميل، اللوحة، التواريخ، المبالغ، **العملة**). ثم تشغّل:

```
npm run eganis:check
```

يجرّب كل عملية ويقول ما نجح وما فشل. ترسل لي المخرجات وأصلّح ما فيها حتى تصير كلها خضراء.

بعدها في `.env`:

```env
EGANIS_DRIVER=browser
```

وتصير كل بياناتك الحقيقية داخل التطبيق: لوحة اليوم، العقود، الأسطول، ومحاسبة المستأجرين
بالليرة والدولار.

---

## أسئلة متوقّعة

**هل هذا آمن؟** الأداة تقرأ فقط ولا تضغط أي زر تعديل في لوحتك. كل المخرجات تبقى على
جهازك في مجلد `data/` (مستثنى من git)، ولا تُرسل لأي جهة إلا ما ترسله أنت بنفسك.

**هل يبطئ اللوحة؟** لا — يفتح الصفحات مثل أي متصفّح، مرة كل بضع دقائق حسب الحاجة.

**كم تدوم الجلسة؟** أياماً عادةً. عندما تنتهي، أعِد الخطوة ٣ فقط (نصف دقيقة).
وإن أردت أن يسجّل الدخول تلقائياً بلا تدخّل، نضع اسم المستخدم وكلمة السر في `.env`
على خادمك أنت — لا عندي.

**إذا وصل الـ API من eganis لاحقاً؟** نبدّل سطراً واحداً (`EGANIS_DRIVER=api`) ونستفيد
من السرعة والثبات. كل ما بنيناه يبقى كما هو — التطبيق لا يفرّق بين المصدرين.

**اللوحة لا تظهر جداولاً؟** بعض اللوحات تحتاج ضغطة «بحث» أولاً، أو تضع الجدول داخل
إطار `iframe`. الأداة تنبّهك لذلك، وأرسل لي `summary.json` وأتعامل معه.
